#  Drone Kontrol Sistemi V2.0

Python ile yazılmış modüler bir **drone görev simülasyon sistemi**.  
Proje; kalkış, görev uçuşu, acil durum kontrolü ve iniş aşamalarını gerçekçi mantıkla simüle eder.

---

##  Özellikler

-  Sistem başlatma ve sensör kontrolü  
-  Batarya tüketim hesaplaması  
-  Yavaş yükseliş animasyonu ile kalkış  
-  Görev uçuşu: yönlere göre hareket & görüntü alma  
-  Acil durum analizi (batarya + irtifa)  
-  Normal veya acil iniş  
-  Görev raporu üretimi
